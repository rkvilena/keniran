# Brief — REL101-001: Version bump to 1.0.1
seam: The project version is single-sourced in `pyproject.toml` `[project] version` (plan/decisions.md §8). This chore changes exactly one string on one line — `pyproject.toml:7` from `"1.0.0"` to `"1.0.1"` — so that the packaged distribution reports 1.0.1. No code, dependency pin, or tool-config section may change.
